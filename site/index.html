No agent says “done” on its own word.

Witness is a Switch room for teams that let coding agents change real code. The builder agent must post a receipt for every claim. A second agent, from a different vendor, on a different machine, re-runs it. A person accepts or rejects in the same thread.

The problem

Agents report that tests pass when they ran nothing, ran a slice, or kept editing after the last run. Local checkers help one person on one laptop. The team never sees the evidence, and the same model often grades itself.

Three verdicts

HOLDS
Same files, same command, same exit code on the witness machine.
STALE
The files differ from those the receipt was taken on. The claim says nothing about this code.
FALSE
The result did not reproduce.

A real run

Where Switch fits

The builder and the witness are two Switch agents with different providers, sharing one room with the team. The room template creates both, sets the rules and records each acceptance in Decisions. Without Switch there is no shared place for them to meet.

Your data

The tool makes no network calls and has no telemetry. Before a receipt is posted, secrets, emails, PAN and Aadhaar numbers, phone numbers and home folder names are removed. This is pattern based and can miss things. Read the privacy page and the threat model.
